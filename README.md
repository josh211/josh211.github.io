# Integrated Informatics Service (IIS)
### Center for Collaborative Research in Health Disparities
**University of Puerto Rico Medical Sciences Campus**

---

## About

This is the website for the **Integrated Informatics Service (IIS)**, which combines Bioinformatics, Health Informatics, and Operational Informatics resources into one unified service. The IIS supports researchers and clinicians at the UPR Medical Sciences Campus and is funded by the NIH/NIMHD RCMI grant.

---

## Units

| Unit | Description |
|------|-------------|
| **Health Informatics** | REDCap-based data capture, clinical databases, biostatistics |
| **Bioinformatics** | Genomics, proteomics, RNAseq, DNAseq, metagenomic analysis |
| **Biomedical Data Science** | AI/ML modeling, predictive analytics, data visualization |

## Adding Staff Photos

Place staff headshot images in the `images/` folder and reference them in `index.html`:

```html
<img class="staff-photo" src="images/filename.jpg" alt="Photo of Name" />
```

Recommended photo size: **200×240 px** (portrait orientation).
